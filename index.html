Test-Time Meta-Adaptation with Self-Synthesis
Zeyneb N. Kaya*, Nick Rui*
ICLR Workshop on AI with Recursive Self-Improvement, 2026

arXiv / co-first

MASS meta-learns LLMs that generate problem-specific synthetic curricula and self-update at inference. On MATH-500, this improved accuracy by 16 points over naive GRPO and test-time training.

Where's the Plan? Locating Latent Planning in Language Models with Lightweight Mechanistic Interventions
Nicole Ma*, Nick Rui*
ICML Workshop on Mechanistic Interpretability, 2026

arXiv / co-first

Future-token plans become linearly decodable with scale, but only some models causally use them. In Gemma-3-27B the causal driver of rhyming constraints localizes to a sparse set of deeper attention heads.

Privileged Context as Drift in On-Policy Self-Distillation
Nick Rui
Under review

first author

In on-policy self-distillation, changing the content of privileged context causes about 5× more policy drift than changing the source, so the context itself is a first-class design axis for continual learning.

LLM-as-Environment: Benchmarking Open-Ended Decision Making
Nick Rui
Under review

co-second author

Hybrid LLM and code environments predict real-world state transitions. Replacing code environments with LLMs preserved model rankings (Spearman ρ = 0.857) while evaluating dynamics fidelity via action replay.
